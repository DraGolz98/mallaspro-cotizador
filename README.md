# MallasPro - Sistema de Cotización
Aplicación web desarrollada en PHP nativo para gestión de cotizaciones de mallas deportivas.

## Tecnologías
PHP 8.0, MySQL, HTML5, CSS3, .htaccess

## Funcionalidades  
- Sistema de login/logout: admin.php, logout.php
- Módulo de cotización: cotizar.php
- Panel de administración completo
- Estructura modular con .htaccess

## Ejecución
1. Copiar carpeta a htdocs de XAMPP
2. Iniciar Apache + MySQL
3. http://localhost/mallas-prueba
