# MallasPro - Sistema de Cotización

Aplicación web desarrollada en PHP nativo para gestión y cotización automática de mallas deportivas. 
Proyecto construido en 1 semana aplicando arquitectura MVC.

## 🚀 Tecnologías
PHP 8.0 | MySQL | HTML5 | CSS3 | JavaScript | .htaccess | MVC

## ✨ Funcionalidades Principales
- *Landing responsiva*: Diseño mobile-first con Bootstrap + CSS personalizado
- *Cotizador dinámico*: Cálculo automático por m² según calibre 12/14/16 y hueco 35/40/45mm 
- *Tabla de precios dinámica*: Actualización en tiempo real sin recargar página
- *Panel de administración*: CRUD completo + login/logout con sesiones PHP seguras
- *CTA a WhatsApp*: Conversión directa de leads desde la cotización

## ⚡ Ejecución Local
1. Clonar repo en htdocs/ de XAMPP: C:/xampp/htdocs/mallaspro-cotizador
2. Iniciar Apache + MySQL desde XAMPP
3. Importar database.sql en phpMyAdmin 
4. Acceder a: http://localhost/mallaspro-cotizador
